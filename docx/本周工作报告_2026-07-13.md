# 本周工作报告

**时间**：2026-07-09 ~ 2026-07-13  
**项目**：RTAB-Map + FAST-LIO + Nav2 导航栈  
**工作重点**：相机驱动接入、外部代码适配、导航启动与参数优化

## 一、调试相机驱动并接入 ROS2 / 当前项目

本周完成了相机驱动在 ROS2 系统中的接入调试，并将相机数据链路并入当前 `rtabmap_nav2_stack` 项目。

主要工作：

1. **Orbbec 相机驱动接入**
   - 新增并调通 Orbbec 相机启动链路：`fastlio_mapping_orbbec.launch.py`、`bringup_orbbec.launch.py`。
   - 通过 `astra_camera` 启动 Orbbec RGB-D 相机，接入彩色图、深度图和相机内参话题。
   - 支持 `lidar_rgbd`、`lidar_stereo`、`lidar_mono` 等传感器组合模式。
   - 配置深度和彩色同步、深度配准、分辨率和帧率参数。

2. **相机数据接入 RTAB-Map**
   - 将相机话题映射到 RTAB-Map 所需输入：
     - `/camera/color/image_raw`
     - `/camera/depth/image_raw`
     - `/camera/color/camera_info`
     - `/rgbd_image`
   - 保留 FAST-LIO 输出的 `/Odometry` 和 `/cloud_registered_body`，形成视觉 + 激光融合建图/定位链路。

3. **TF 链路整理**
   - 统一由项目启动文件发布相机 TF，关闭相机驱动自身 TF 发布，避免 TF 冲突。
   - 补齐 `camera_link`、`camera_color_frame`、`camera_color_optical_frame`、`camera_depth_frame`、`camera_depth_optical_frame` 等静态 TF。
   - 根据现场调试结果修正相机 pitch 方向，保证相机坐标系与机器人坐标系关系正确。

## 二、适配外部代码到我们的驱动与项目链路

本周对外部 RTAB-Map / 相机示例代码进行了项目化适配，使其能够配合我们的底盘、Livox MID360、FAST-LIO 和相机驱动运行。

主要工作：

1. **适配 RTAB-Map 启动方式**
   - 新增 `rtabmap_bridge.launch.py` 作为项目统一的 RTAB-Map 桥接启动文件。
   - 将 RTAB-Map 的输入改为当前项目实际输出：
     - 里程计使用 FAST-LIO 的 `/Odometry`。
     - 点云使用 FAST-LIO 去畸变点云 `/cloud_registered_body`。
     - 相机使用 Orbbec / RealSense 驱动发布的话题。
   - 禁用 RTAB-Map 自带的视觉里程计和 ICP 里程计，避免与 FAST-LIO 重复发布 odom。

2. **适配不同相机驱动的话题差异**
   - 整理 Orbbec 与 RealSense 两套相机启动文件，统一为项目可切换的 `sensor_profile` 模式。
   - 对 RGB-D、双目、单目模式分别配置话题、同步方式和 RTAB-Map 参数。
   - 针对 Orbbec 的深度话题、IR 话题、camera_info 话题进行重映射和参数调整。

3. **保留项目原有主链路**
   - 保持 Livox MID360 + FAST-LIO 作为局部连续里程计主链路。
   - RTAB-Map 负责全局建图、回环、重定位和 `map -> odom`。
   - Nav2 继续消费 `/map`、`/Odometry` 和 TF 树进行规划控制。

## 三、优化导航并更新导航启动文件

围绕导航稳定性和启动便利性，本周对 Nav2 参数和启动文件进行了更新。

主要工作：

1. **更新导航启动入口**
   - `bringup_orbbec.launch.py` 集成 Livox、Orbbec、FAST-LIO、RTAB-Map 定位、Nav2 和 RViz。
   - 增加 `start_livox`、`start_camera`、`mode`、`sensor_profile`、`database_path` 等参数，便于建图/定位/导航切换。
   - 默认导航参数切换到 `nav2_cuda_mppi.yaml`，用于 CUDA MPPI 控制器链路。

2. **优化 Nav2 参数**
   - 调整全局代价地图机器人半径参数，提升路径规划通过性。
   - 保持局部代价地图、全局代价地图和 RTAB-Map 地图输出的衔接。
   - 更新 RViz 导航配置，便于现场观察地图、路径、代价地图和定位状态。

3. **完善定位调试脚本**
   - 更新 `scripts/start_with_scan_context_localization.sh`，在接收到 `/initialpose` 后打印初始位姿的 x、y、z、w 信息。
   - 方便现场确认 Scan Context 重定位结果是否正常写入导航链路。

4. **更新使用说明**
   - README 中补充 Orbbec + Livox + FAST-LIO + RTAB-Map + Nav2 的快速启动命令。
   - 明确建图和导航两个入口的参数用法，以及关键输入话题。
