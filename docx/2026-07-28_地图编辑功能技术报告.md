# 离线地图编辑功能技术报告

**原始日期**：2026-07-28  
**更新日期**：2026-07-30  
**工程**：`rtabmap_nav2_stack`  
**核心包**：`src/map_paint_editor_plugin`

## 1. 功能范围

地图编辑器现在只用于离线修改 Nav2 常用的 `PGM + YAML` 静态地图。

保留功能：

- 从本地 YAML/PGM 加载地图；
- 将栅格绘制为 `FREE(0)`、`BLOCK(100)` 或 `UNKNOWN(-1)`；
- 缩放、平移和调整圆形画笔；
- 覆盖保存 PGM/YAML；
- 保留分辨率、地图原点和原点朝向。

已删除功能：

- 订阅在线 `nav_msgs/OccupancyGrid`；
- 发布 `/map` 或 `/map_edited`；
- 在导航启动文件中自动启动编辑器；
- 清空 Nav2 全局代价地图；
- 重新发送导航目标；
- 导航运行过程中的在线地图修改。

## 2. 模块组成

| 文件 | 作用 |
|---|---|
| `map_paint_editor.py` | 创建 Qt 程序并驱动编辑器节点 |
| `map_editor/node.py` | 本地地图加载、绘制状态和保存 |
| `map_editor/canvas.py` | PyQt5 地图界面、鼠标操作、缩放和平移 |
| `map_editor/occupancy.py` | 栅格数组和灰度图转换 |
| `map_editor/storage.py` | 读取和保存 PGM/YAML 地图 |
| `map_paint_editor.launch.py` | 独立离线启动入口 |

## 3. 工作流程

```text
本地 PGM/YAML
      ↓
MapStorage 加载
      ↓
NumPy 二维栅格
      ↓
PyQt5 离线绘制
      ↓
覆盖保存 PGM/YAML
      ↓
退出编辑器
      ↓
导航启动后由 map_server 单独加载
```

编辑器不创建地图发布者、地图订阅者、Nav2 服务客户端或目标话题接口。

## 4. 使用方法

先退出正在运行的导航，再独立启动编辑器：

```bash
ros2 launch map_paint_editor_plugin map_paint_editor.launch.py \
  load_yaml_path:=/data/maps/site_a/map.yaml \
  save_yaml_path:=/data/maps/site_a/map.yaml
```

编辑完成后点击 `SAVE OVERWRITE` 并退出。随后启动导航：

```bash
ros2 launch robot_bringup bringup.launch.py \
  mode:=navigation \
  use_edited_map:=true \
  edited_map_yaml:=/data/maps/site_a/map.yaml
```

`use_edited_map` 只表示导航加载已经离线保存好的静态地图，不会启动编辑器。

## 5. 地图格式

保存规则：

- 障碍区域：灰度 `0`；
- 自由区域：灰度 `254`；
- 未知区域：灰度 `205`；
- `occupied_thresh: 0.650`；
- `free_thresh: 0.196`。

`free_thresh` 使用 `0.196`，以避免灰度 `205` 的未知栅格被重新加载为自由区域。

## 6. 当前限制

- `SAVE OVERWRITE` 会覆盖原地图；
- 没有撤销、重做和自动备份；
- 没有直线、矩形或多边形画笔；
- 只支持本地文件，不支持运行中的 ROS 地图话题。

## 7. 结论

当前地图编辑功能为纯离线工具。正式导航期间只有 RTAB-Map 或
`nav2_map_server` 发布地图，编辑器不会参与 ROS 地图链路。
