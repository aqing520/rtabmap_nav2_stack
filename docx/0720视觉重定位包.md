## 1. 概述

### 1.1 解决的问题

传统 Nav2 导航启动后，需要操作人员在 RViz 中手动点击 **"2D Pose Estimate"** 给定机器人初始位置，才能正常导航。这个过程：

- 依赖人工操作，不够自动化
- 如果初始位置给错，导航路径规划会出错
- 在无人值守场景下无法实现自主启动

### 1.2 解决方案

`visual_initial_pose` 包实现了**基于视觉的自动初始定位**：利用 RTAB-Map 建图时存储的视觉特征数据库，与当前摄像头图像进行匹配，自动确定机器人在地图中的位置，定位成功后自动激活 Nav2 导航栈。

### 1.3 核心特点

- **全自动**：启动后无需人工干预，摄像头自动匹配定位
- **安全**：定位未完成前 Nav2 不会激活，避免在错误位置规划路径
- **可配置**：支持调整匹配阈值、超时时间、fallback 策略
- **独立模块**：与 RTAB-Map 主进程解耦，独立加载数据库做匹配

## 3. 重定位原理

### 3.1 RTAB-Map 视觉定位基础

RTAB-Map（Real-Time Appearance-Based Mapping）是一个基于外观的 SLAM 系统。建图时，它将每一帧的关键帧图像提取视觉特征（默认 ORB），连同位姿一起存入数据库。

**建图阶段**：
```
摄像头图像 → 提取 ORB 特征点 → 存入数据库（特征描述子 + 3D 位姿）
```

**定位阶段**：
```
当前图像 → 提取 ORB 特征 → 与数据库中的特征做匹配 → 计算位姿变换 → 得到机器人位置
```

### 3.2 匹配判定流程

`visual_initial_pose_node` 每隔 1 秒处理一帧 RGB-D 图像，执行以下步骤：

```
1. 获取当前 RGB-D 图像
   │
2. 查询 base_footprint → camera_link 的 TF 变换
   │
3. 将图像送入 RTAB-Map 本地实例（只读模式，不修改数据库）
   │
4. RTAB-Map 尝试与数据库中的节点做视觉闭环匹配
   │
5. 提取匹配结果：
   ├── loop_closure_id    （匹配到的数据库节点 ID）
   ├── score              （后验概率分数）
   ├── visual_inliers     （视觉内点数量）
   ├── visual_inliers_ratio（内点比例）
   ├── best_second_ratio  （最佳/次佳候选比）
   └── covariance         （定位协方差）
   │
6. 判定是否接受：
   ├── loop_closure_id > 0           ← 必须找到闭环
   ├── score ≥ min_hypothesis        ← 分数过阈值（默认 0.08）
   ├── visual_inliers ≥ min_visual_inliers  ← 内点够多（默认 10）
   ├── best/second ratio ≥ 0.8       ← 匹配够明确
   ├── covariance 在合理范围内        ← 定位够确定
   └── 连续 N 次匹配同一节点          ← 防止误匹配（默认 2 次）
   │
7. 接受 → 发布位姿 → 激活 Nav2
   拒绝 → 继续等待下一帧
```

### 3.3 关键参数说明

| 参数 | 默认值 | 说明 |
|---|---|---|
| `min_hypothesis` | 0.08 | RTAB-Map 后验概率阈值，越高越严格 |
| `min_visual_inliers` | 10 | 最少视觉匹配内点数 |
| `min_best_second_ratio` | 0.8 | 最佳/次佳候选比，Lowe's ratio test |
| `max_features` | 1500 | 最大特征点数，越多匹配越可靠但越慢 |
| `required_confirmations` | 2 | 需要连续匹配同一节点的次数 |
| `localization_timeout_sec` | 30 | 视觉定位超时时间（秒） |
| `allow_last_pose_fallback` | false | 超时后是否使用数据库最后位姿 |
| `max_linear_variance` | 1.0 | 定位线性协方差上限 |
| `max_yaw_variance` | 1.0 | 定位航向角协方差上限 |

### 3.4 特征匹配示意

```
建图时存储的特征            当前摄像头特征
  ┌─────────────┐          ┌─────────────┐
  │  ●   ●      │          │  ●   ●      │
  │     ●   ●   │    ◄──   │     ●   ●   │
  │  ●      ●   │  匹配    │  ●      ●   │
```

## 4. 状态机

`visual_initial_pose_node` 内部是一个有限状态机：

```
                    ┌──────────────────────────────────┐
                    │         INITIALIZING              │
                    │  加载 RTAB-Map 数据库（只读）       │
                    └──────────────┬───────────────────┘
                                   │ 数据库加载成功
                                   ▼
                    ┌──────────────────────────────────┐
              ┌────►│          SEARCHING               │
              │     │  订阅 /rgbd_image                 │
              │     │  每 1s 处理一帧，做视觉匹配         │
              │     │  发布 /visual_initial_pose/status  │
              │     └────┬──────────┬─────────────────┘
              │          │          │
              │     匹配成功    30s 超时
              │          │          │
              │          │     ┌────┴────────────────────┐
              │          │     │ allow_last_pose_fallback │
              │          │     │  = true → 使用数据库位姿  │
              │          │     │  = false → 继续搜索/失败  │
              │          │     └────┬────────────────────┘
              │          │          │
              │          ▼          ▼
              │     ┌──────────────────────────────────┐
              │     │     WAITING_TF_CONFIRMATION       │
              │     │  发布 /initialpose（重复 3 次）     │
              │     │  等待 map→base_footprint TF 更新   │
              │     │  验证 TF 与发布位姿一致             │
              │     └──────────────┬───────────────────┘
              │                    │ TF 确认成功
              │                    ▼
              │     ┌──────────────────────────────────┐
              │     │     ACTIVATING_COLLISION          │
              │     │  调用 lifecycle service            │
              │     │  激活 Collision Monitor            │
              │     └──────────────┬───────────────────┘
              │                    │ 激活成功
              │                    ▼
              │     ┌──────────────────────────────────┐
              │     │     ACTIVATING_NAVIGATION         │
              │     │  调用 lifecycle service            │
              │     │  激活 Nav2 全部节点                 │
              │     └──────────────┬───────────────────┘
              │                    │ 激活成功
              │                    ▼
              │     ┌──────────────────────────────────┐
              │     │          COMPLETE                 │
              │     │  机器人可以接收导航目标              │
              │     └──────────────────────────────────┘
              │
     TF 确认超时 / lifecycle 失败
              │
              ▼
        ┌──────────┐
        │  FAILED   │
        └──────────┘
```

## 5. 使用方式

### 5.1 快速启动

```bash
cd /home/wheeltec/xz/rtabmap_nav2_stack
source install/setup.bash
bash scripts/start_orbbec_navigation_visual_initial_pose.sh
```

### 5.2 环境变量覆盖

启动脚本支持通过环境变量覆盖默认参数：

```bash
# 使用自定义数据库路径
DATABASE_PATH=/path/to/my.db bash scripts/start_orbbec_navigation_visual_initial_pose.sh

# 启用 fallback（视觉定位失败时使用数据库最后位姿）
ALLOW_LAST_POSE_FALLBACK=true bash scripts/start_orbbec_navigation_visual_initial_pose.sh

# 关闭 RViz
ENABLE_RVIZ=false bash scripts/start_orbbec_navigation_visual_initial_pose.sh

# 使用立体相机配置
SENSOR_PROFILE=lidar_stereo bash scripts/start_orbbec_navigation_visual_initial_pose.sh
```

### 5.3 直接使用 ros2 launch

```bash
ros2 launch visual_initial_pose orbbec_navigation_visual_initial_pose.launch.py \
  database_path:=./rtabmap_orbbec.db \
  sensor_profile:=lidar_rgbd \
  min_hypothesis:=0.08 \
  min_visual_inliers:=10 \
  allow_last_pose_fallback:=true
```

### 5.4 监控定位状态

```bash
# 查看定位状态
ros2 topic echo /visual_initial_pose/status

# 查看是否成功
ros2 topic echo /visual_initial_pose/success

# 查看匹配分数
ros2 topic echo /visual_initial_pose/candidate_score

# 查看匹配到的节点 ID
ros2 topic echo /visual_initial_pose/candidate_id
```

### 5.5 状态说明

| 状态 | 含义 |
|---|---|
| `state=searching` | 正在搜索匹配，detail 中有失败原因 |
| `state=confirming` | 匹配成功，正在连续确认 |
| `state=localized` | 定位完成，已发布位姿 |
| `state=tf_confirmed` | TF 已更新，与发布位姿一致 |
| `state=complete` | 全部完成，Nav2 已激活 |
| `state=fallback` | 使用数据库最后位姿作为 fallback |
| `state=failed` | 定位失败 |
| `state=alarm` | 报警（传感器超时等） |

## 6. 配置文件

### 6.1 节点配置

配置文件位置：`src/visual_initial_pose/config/visual_initial_pose.yaml`

```yaml
/**:
  ros__parameters:
    use_sim_time: false

    # 数据库与话题
    database_path: "./rtabmap_orbbec.db"
    rgbd_topic: "/rgbd_image"
    map_frame: "map"
    base_frame: "base_footprint"

    # 超时设置
    process_interval_sec: 1.0        # 处理间隔（秒）
    sensor_wait_timeout_sec: 30.0    # 等待传感器数据超时
    localization_timeout_sec: 30.0   # 视觉定位超时
    continue_search_after_timeout: true

    # 匹配阈值
    min_hypothesis: 0.08             # 最低接受分数
    min_visual_inliers: 10           # 最少内点数
    min_visual_inliers_ratio: 0.0    # 内点比例（0.0=不检查）
    min_best_second_ratio: 0.8       # 最佳/次佳比（Lowe's ratio）
    max_optimization_error_ratio: 3.0
    max_linear_variance: 1.0         # 线性协方差上限
    max_yaw_variance: 1.0            # 航向协方差上限
    required_confirmations: 2        # 连续确认次数

    # 特征检测
    detector_strategy: -1            # -1=使用数据库默认
    feature_type: -1                 # -1=使用数据库默认（ORB）
    max_features: 1500               # 最大特征点数
    flatten_to_2d: true              # 定位结果投影到 2D

    # 位姿发布
    publish_initialpose: true
    initialpose_publish_repetitions: 3
    initialpose_publish_interval_sec: 0.2

    # Nav2 激活
    activate_nav2_on_success: true
    activate_collision_monitor: true
    tf_confirmation_timeout_sec: 10.0
    tf_settle_delay_sec: 0.5
```

### 6.2 前置条件参数

| 条件 | 说明 |
|---|---|
| `database_path` | 必须指向一个有效的 RTAB-Map 数据库文件（由建图阶段生成） |
| `rgbd_topic` | 必须有节点发布此话题（由 `rgbd_sync` 节点提供） |
| TF 树 | `base_footprint → camera_link` 的 TF 必须可用 |

## 9. 故障排查

### 9.1 常见问题

| 问题 | 可能原因 | 解决方法 |
|---|---|---|
| 一直 searching，不成功 | 特征匹配不上 | 降低 `min_hypothesis`，增加 `max_features` |
| `No RGB-D data received` | 相机没出图 | 检查 `/camera/color/image_raw` 是否有数据 |
| `Cannot get TF` | TF 树不完整 | 检查 `base_footprint → camera_link` TF |
| `Database contains no usable nodes` | 数据库为空 | 重新建图 |
| `localization timed out` | 30s 内未匹配成功 | 增加 `localization_timeout_sec` 或启用 fallback |
| 匹配分数很低（< 0.1） | 环境变化大 | 重新建图，或降低阈值 |

### 9.2 调试命令

```bash
# 检查相机图像
ros2 topic hz /camera/color/image_raw

# 检查 RGBD 同步
ros2 topic hz /rgbd_image

# 检查 TF 树
ros2 run tf2_tools view_frames

# 检查 RTAB-Map 数据库
rtabmap-databaseViewer rtabmap_orbbec.db

# 查看定位状态日志
```

### 9.3 调参建议

**匹配率低**：
